### 👋 Sobre mim

Sou **DevOps do [LabNuven](https://labnuven.com.br)**, o Núcleo de Visão Computacional e Engenharia do IFCE, onde cuido da infraestrutura, do deploy e da operação dos projetos de PD&I em IA e visão computacional do laboratório.

Fora dele, toco o [**Morales Dev**](https://www.morales.dev.br): construo sistemas web sob medida e cuido de onde eles rodam — servidores próprios, containers e deploy, sem depender de nuvem cara.

```yaml
cargo:     DevOps @ LabNuven (IFCE)
foco:      [infraestrutura, deploy, self-hosting, sistemas web, IA aplicada]
servidor:  Ubuntu + Docker + Dokploy, atrás de Cloudflare Tunnel
monitor:   Beszel + Uptime Kuma
filosofia: menos hype, mais construção
lado_b:    SaaS e sites para pequenos negócios via Morales Dev
```

### 🚀 Projetos em produção

> Os repositórios são privados (sistemas de clientes e projetos de pesquisa), mas tudo abaixo está no ar, em servidores que eu mesmo administro.

#### 🔬 Pesquisa aplicada — LabNuven

O [NUVEN](https://www.labnuven.com.br) é o Núcleo de Visão Computacional e Engenharia do IFCE, dentro de uma unidade EMBRAPII, com projetos de PD&I em IA desde 2020. Minha parte é fazer a pesquisa virar sistema no ar:

| Frente | O que faço |
|---|---|
| Plataforma de deploy | Servidor do laboratório com Docker e Dokploy: cada projeto com ambiente próprio, deploy a partir do GitHub e domínio com HTTPS |
| Protótipos de IA | Coloco no ar frontends, APIs e bancos vetoriais de projetos em visão computacional, biometria e processamento de linguagem natural |
| Dados para treino | Mantenho a plataforma de anotação usada para montar os datasets dos modelos |
| Automações | Fluxos de integração entre os sistemas e as rotinas do laboratório |
| Operação | Logs, atualizações e estabilidade dos serviços, além do site institucional do núcleo |
